Millquas Productions · Crosspost

Privacy Policy

Last updated 26 November 2026

Crosspost is a private posting tool made and used by Millquas Productions. It runs only on Millquas Productions' own computer and posts its own videos and photos to its own social accounts. It is not offered to the public, has no other users, and does not collect, sell or share anyone's personal data.

What Crosspost is

Crosspost is a small desktop app that schedules and publishes the owner's content to YouTube, Instagram, Facebook, TikTok and Pinterest. There is no Crosspost website, server or account system. Everything it does happens on the owner's computer.

Information Crosspost uses from Pinterest

When the owner connects their Pinterest account, Crosspost asks Pinterest for permission to:

  • Read the account name, to show which account is connected.
  • Read and create boards, so the owner can choose which board a Pin goes to.
  • Create Pins from the owner's own videos and photos, with the title, description and link the owner wrote.

Crosspost does not read other people's Pins, profiles, followers, messages or analytics.

Where information is stored

The sign-in tokens Pinterest issues, the connected account name and the chosen default board are saved in a file on the owner's computer. The posting schedule and post captions are saved there too. None of this is uploaded to any server run by Crosspost, because there isn't one.

Who information is shared with

Crosspost sends content only to the platform it is posting to, at the owner's request. A Pin goes to Pinterest and nowhere else. Crosspost has no advertising, analytics, tracking or cookies, and never sells or shares data with anyone.

Keeping and deleting information

Information stays on the owner's computer until the owner deletes it. To disconnect Pinterest, the owner can remove Crosspost's access in Pinterest's settings under Security and logins (or Apps), and delete the saved Pinterest file from Crosspost's credentials folder. Pins already published stay on Pinterest until the owner deletes them there.

Children

Crosspost is a personal tool for one adult owner and is not directed at children.

Changes to this policy

If Crosspost starts using information differently, this page will be updated and the date at the top will change.

Crosspost is operated by Millquas Productions. Questions about this policy can be sent to Millquas Productions through the Pinterest account this app is registered to.
